# 全站彩蛋浮层设计

日期：2026-07-29  
状态：待实现  
范围：全站（排除 `/admin`）仪式感触发 → 居中签名面板

## 目标

在 HyperOS 设计系统文档站埋入个人彩蛋：需要短时间连点才能打开，打开后是一张低调浮层卡片，不打断阅读路径、不进入导航与搜索索引。

## 非目标

- 独立路由页、可分享深链、SEO / `llms` 收录
- Konami 键盘码、音效、全屏特效
- 排除链接/按钮点击（误触仅靠时间窗控制）
- Storybook / 可交互 Web 组件 demo

## 触发规则

| 项 | 约定 |
|----|------|
| 范围 | 全站；**排除**路径前缀 `/admin` |
| 事件 | 捕获阶段监听 `click`（触控点按同等计入） |
| 阈值 | **1.2 秒内**累计 **4** 次点击 |
| 超时 | 超过窗口则计数清零，重新累计 |
| 打开后 | 忽略继续连点，直至关闭 |
| 关闭 | 点遮罩、点关闭按钮、按 `Esc` |
| 再次触发 | 关闭后允许重新连点打开 |

## 面板内容

| 区域 | 文案 |
|------|------|
| 标题 | 恭喜你来到了无人区 |
| 正文 | 规范都在外面，这里只留给偶然路过的人。 |
| 页脚 | 薛困惑，2026 年 7 月 |

## 交互与可访问性

- 居中卡片 + 半透明遮罩；淡入并轻微上移，时长短、无花哨循环动画
- 视觉跟随站点 chrome（中性色、细边框），不引入新的品牌色体系
- 打开时：`role="dialog"`、`aria-modal="true"`，焦点落入面板（优先关闭按钮或面板容器）
- 关闭后：焦点回到触发前的位置（若仍可聚焦）
- 移动端布局：卡片宽度受限、边距充足，保证可点关闭

## 架构与落点

```text
src/components/easter-egg/
  EasterEggProvider.tsx   # 点击计数、开关状态、Esc / 路由排除
  EasterEggPanel.tsx      # 遮罩 + 卡片 UI + 文案
src/app/layout.tsx        # 在根布局挂载 Provider（Client 子树）
```

- `EasterEggProvider` 为 Client Component；根布局其余部分保持 Server Component 结构不变
- 文案可内联在 `EasterEggPanel`（或同目录常量）；无需 CMS / Tina schema
- 不注册 Fumadocs 侧栏、不写入 `content/docs/`、不改 `meta.json`

## 行为细节

1. 使用 `pathname`（如 `usePathname`）判断是否以 `/admin` 开头；在 admin 下不绑定监听、不渲染面板。
2. 点击时间戳队列：仅保留窗口内的点击；长度达到 4 时 `open = true` 并清空队列。
3. 面板打开期间 `document` 可按需 `overflow: hidden`，避免背景滚动（若与现有布局冲突则省略，优先不破坏 docs 阅读）。
4. 无 URL 同步、无 `localStorage`、无「今日已看过」限制——每次符合触发即可打开。
