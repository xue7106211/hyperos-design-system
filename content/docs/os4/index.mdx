## 文档结构

侧栏按用途划分，各一级目录均有总览页：

- **通用设计标准** — 理念、原则、Token、布局、动效、文案与包容性设计
- **控件与组件** — 导航、操作、输入、容器与展示类规范（设计稿 + Token + Android 代码参考）
- **人机交互标准** — 硬件、手势、键鼠与交互归一
- **系统特性与能力标准** — 搜索、编辑、加载、权限等系统能力
- **多端设备标准** — 多端适配规范
- **设计模式** — 页面模式、加载刷新、引导与系统能力等应用层模式

图标库与站外资产见 [设计资源中心](/resources)，也可打开 [HyperOS 图标库](/docs/os4/resources/icons) 预览。

- **底部导航 Bottom Navigation** — 入库底栏导航规范与配图
